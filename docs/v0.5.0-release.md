## Required maintenance fix

PR #99 fixes a worker start/stop race in the new kernel. Inspection and a
real-thread, Event-ordered reproduction demonstrate the same bug in the old
egress runtime: stop joins a registered worker before Thread.start finishes,
raising RuntimeError before capability deactivation. The release applies only
the is_alive guard to the old runtime, without importing the kernel.
Two tests cover start success/failure, deactivation, retained worker ownership,
retry cleanup, error reporting, and idempotent close. Both fail before the fix.
The runtime's other shutdown behavior and protocol remain unchanged.
