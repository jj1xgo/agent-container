# v0.5.0 — Phase 5 Family operations

Phase 5 is now available as a separate release line based on its completed,
validated implementation. Main continues Phase 6 broker-kernel development.

- Dedicated Family GitHub App and repository binding, credential-free Codex
  and Claude intake, bounded inbox, preview and per-request host approval,
  Issue creation, duplicate prevention, unknown reconciliation, and audit/cleanup.
- Project-scoped opt-in exact-domain HTTPS egress allowlist.
- Standalone host handover publisher and Claude SessionStart notification.
- Claude setup-token validation and wrapped-paste fixes.
- A minimal backport of the egress worker start/stop race fix: deactivation and
  retry cleanup remain reachable when stop overlaps a worker's pending start.

GitHub App credentials stay on the host; Family uses a separate App from the development
repository broker. Allowlist failure does not fall back to unrestricted runtime
network. Existing 0.x interface and state compatibility caveats still apply.

Install with `git clone --branch v0.5.0 --depth 1 https://github.com/jj1xgo/agent-container.git`.
A clean release-tag checkout reports `agentctl 0.5.0`.

Validation: local container 978, Codex 44, broker sockets 18, forced-unknown 4,
lint, exact-tag CLI and embedded image-layout version checks passed. Required
CI results and the exact final candidate are recorded in PR #100 before publication.
Authenticated Codex/Claude host smoke is the recorded Phase 5 evidence from
September 2 and 4; it was not rerun for this release candidate. Fresh real Podman
CI verification is distinct from that historical authenticated smoke.

Phase 6 kernel changes, managed statusline/trust seeding, and the subsequent
host Codex hook are not part of v0.5.0. The release branch is `release/0.5`;
main moves to `0.6.0-dev` after publication.
